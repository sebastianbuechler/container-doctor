<CardGrid stagger>
  <Card title="Rules decide, a model explains" icon="seti:config">
    Deterministic rules open an incident; the model only ever explains one that
    already exists, and picks at most one action from a closed list of five.
  </Card>
  <Card title="Nothing without you" icon="approve-check">
    Starts in `observe`. `suggest` asks before it acts; `auto` acts only where
    you allowed it, inside rate limits, and checks that it helped.
  </Card>
  <Card title="Restart, never create" icon="warning">
    Docker is reached through a socket proxy that permits restarting a
    container and nothing that could escape one. No mount of your data.
  </Card>
  <Card title="Secrets stay out" icon="seti:lock">
    Logs are scrubbed of tokens and keys before anything is stored or sent to a
    model, and every request it sent can be read back on the dashboard.
  </Card>
  <Card title="Any model" icon="rocket">
    Anthropic or anything OpenAI-compatible - OpenRouter, Gemini, Groq, or a
    local model. A daily budget hard-stops spend.
  </Card>
  <Card title="The whole host" icon="laptop">
    Disks and their fill rate, SMART and RAID, CPU and memory, the network and
    DNS, image updates with release notes, and what changed on each container.
  </Card>
</CardGrid>
